# تطبيق «واجِب» — Flutter (iOS + Android)

تنفيذ تقني لمنصة **واجِب** الموصوفة في [وثيقة المشروع](../README.md):
ذاكرة اجتماعية خاصة تلتقط المناسبات، وترتّبها بدرجة الوجوب، وتنفّذ الواجب
بضغطة واحدة — بقاعدة بيانات محلية على الجهاز بالكامل.

## التشغيل

```bash
flutter pub get
flutter run                    # على جهاز iOS أو Android موصول
flutter test                   # 125 اختباراً
flutter analyze                # بلا ملاحظات
```

بناء نسخ الإصدار:

```bash
flutter build appbundle --release   # Android (Google Play)
flutter build apk --release         # Android (تثبيت مباشر)
flutter build ipa --release         # iOS — يتطلب macOS و Xcode
```

## بنية المشروع

```
lib/
├── models/        # الشخص، المناسبة، المقران، الدفتر، التقويم الهجري، الإعدادات
├── engines/       # المحركات الخمسة + مواقيت الصلاة + معالجة النص العربي
├── data/          # المخزن (ChangeNotifier)، التخزين المحلي، بيانات العرض
├── theme/         # نظام التصميم: النمط العادي، نمط العزاء، نمط كبار السن
└── ui/            # الشاشات: الانضمام، واجبات اليوم، المناسبة، العلاقات، الدفتر، الإعدادات
```

## المحركات الخمسة

| المحرك | الملف | ما ينفّذه |
|---|---|---|
| الالتقاط الذكي | `engines/capture_engine.dart` | يحوّل نص الإعلان (نعي، دعوة، بشارة) إلى حقول منظّمة: الاسم، النوع، **مقر الرجال ومقر النساء منفصلين**، مرساة الصلاة، التواريخ الهجرية والميلادية، رقم التواصل، المدة — مع درجة اكتمال وتحذيرات تُلزم بالمراجعة البشرية |
| خريطة العلاقات | `models/person.dart` + `ui/relations/` | دوائر وظيفية (عائلة، أصهار، ديوانية، زمالة، جيرة، دراسة) ودرجة قرب 0–100 يعدّلها المستخدم |
| درجة الوجوب | `engines/obligation_engine.dart` | خمسة عوامل مرجّحة: القرب 40%، نوع المناسبة 25%، المعاملة بالمثل 15%، الإلحاح 10%، إمكانية الحضور 10% → **واجب مؤكد / يُستحسن / اختياري** مع شرح الأسباب |
| دفتر المعاملة بالمثل | `engines/reciprocity_ledger.dart` | رصيد مرجّح لكل شخص، وتذكير بما عليك أنت — بلا مشاركة ولا تصدير ولا صياغة اتهامية |
| التنفيذ | `engines/message_engine.dart` + `engines/action_layer.dart` | بنك عبارات بالفصحى واللهجة حسب المناسبة ودرجة القرب، إنابة، سوق موردين، واقتراح نقوط خاص |

## الخطوط الحمراء — مثبّتة في الشيفرة ومحروسة باختبارات

| القاعدة | التنفيذ | الاختبار |
|---|---|---|
| لا إرسال آلي لأي رسالة | `MessageDispatcher` يرمي `AutoSendBlockedException` بلا مصادقة، وأي تعديل يُبطل المصادقة | `message_engine_test.dart` + اختبار واجهة |
| لا إعلانات تجارية على العزاء | `VendorCatalog.promotionsFor` يعيد فارغاً في المناسبات الحزينة، وخدماتها مقصورة على ما يليق | `action_layer_test.dart` + اختبار واجهة |
| لا تصنيف قبلي أو طائفي أو مناطقي | لا حقل من هذا النوع في أي نموذج | فحص ثابت لكامل `lib/` في `red_lines_test.dart` |
| لا نشر عام ولا متابعون ولا ترتيب للأشخاص | لا مفهوم من هذه المفاهيم في الشيفرة؛ الترتيب للواجبات لا للناس | فحص ثابت + اختبار نموذج |
| الخصوصية الافتراضية هي الأشد تحفّظاً | كل مفاتيح المشاركة `false` افتراضياً | `red_lines_test.dart` |
| المقران حقلان إلزاميان منفصلان | `menVenue` و `womenVenue` في النموذج، والواجهة تختار وجهة المستخدم تلقائياً | اختبار نموذج + اختبار واجهة |
| العزاء ثلاثة أيام | `OccasionType.condolence.defaultDurationDays == 3` مع حساب اليوم الحالي | `red_lines_test.dart` |

## ملاحظات تقنية

- **التقويم الهجري** محسوب بالخوارزمية الجدولية (الكويتية)، وقد يفارق الرؤية
  الشرعية بيوم؛ لذلك يُعرض التاريخان معاً ويبقى الميلادي مرجع الحسابات.
- **مواقيت الصلاة** محسوبة فلكياً بطريقة أم القرى (الفجر 18.5°، العشاء بعد
  المغرب بـ 90 دقيقة، العصر شافعي) لإحداثيات مدينة الكويت — تُستخدم لترجمة
  «بعد صلاة العصر» ولكتم التنبيهات أثناء الصلاة.
- **التخزين** محلي بالكامل (`shared_preferences`)؛ لا يغادر أي شيء الجهاز.
- **الاعتماديات**: `flutter_localizations` و `shared_preferences` فقط.
