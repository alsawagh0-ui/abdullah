# فيديوهات الأربعين النووية (42 فيديو)

كل مجلد (01 … 42) فيه `script.json`: نص الشرح باللهجة الكويتية سطر سطر (`text`)، ومعه النص اللي يطلع على الشاشة بالفصحى (`show`).
النصوص مأخوذة من محتوى الأربعين المطابَق على شرح ابن دقيق العيد وجدول الصفوة (الراوي ومن أخرجه).

## التشغيل على جهازك (مهارة video-ad-editor — وضع «شرح بالموشن»)
1. افتح Claude Code على جهازك (Local) وثبّت مهارة `video-ad-editor`.
2. قل له: «سو فيديو موشن من هالنص» وأعطه مجلد الحديث، مثلاً `video/h40/07`.
3. الصوت: الأفضل صوتك أنت — سجّل النص وأعطه الملف (`voice.py <المشروع> --own صوتي.wav`)،
   أو صوت آلي كويتي (`ar-KW-FahedNeural`).
4. الألوان المقترحة (نفس الموقع): خلفية #0F1412، نص #E6ECE8، تمييز #5CB496.

⚠️ القاعدة: لا يُضاف أي كلام أو معلومة غير الموجودة في `script.json`.
